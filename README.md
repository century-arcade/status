# status

The public status page of the Century Arcade crossword pipeline, served at https://status.centuryarcade.org/ by GitHub Pages.

- `index.html`: a static page, no scripts.
- `status.json`: the same facts, machine-readable (schema 1): per-check colours, the last good nightly date, when the gxd corpus and its index builds last updated, and whether an incident is open.

Both files are generated by a health check that runs elsewhere and pushed here; don't edit them by hand. Nothing here contains logs, diagnoses or credentials.
