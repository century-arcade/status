[![pages](https://img.shields.io/github/actions/workflow/status/century-arcade/status/pages%2Fpages-build-deployment?branch=main&label=pages)](https://github.com/century-arcade/status/actions/workflows/pages/pages-build-deployment) [![pipeline](https://img.shields.io/endpoint?url=https://status.centuryarcade.org/badge.json)](https://status.centuryarcade.org/) [![nightly](https://img.shields.io/endpoint?url=https://status.centuryarcade.org/badge-downloader.json)](https://status.centuryarcade.org/)

The public status page of the Century Arcade crossword pipeline, served at https://status.centuryarcade.org/ by GitHub Pages.

- `index.html`: a static page, no scripts.
- `status.json`: the same facts, machine-readable (schema 1): per-check colours, the last good nightly date, when the gxd corpus and its index builds last updated, and whether an incident is open.
- `badge.json`, `badge-downloader.json`: [shields.io endpoint badges](https://shields.io/badges/endpoint-badge) for the overall colour and the nightly download. To show one in another README:

      [![pipeline](https://img.shields.io/endpoint?url=https://status.centuryarcade.org/badge.json)](https://status.centuryarcade.org/)

All of these files are generated by a health check that runs elsewhere and pushed here; don't edit them by hand. Nothing here contains logs, diagnoses or credentials.
